# Syncora

Syncora es una aplicación fullstack de gestión empresarial desarrollada como proyecto de prácticas.

El objetivo del proyecto es crear una plataforma donde diferentes equipos puedan organizar proyectos, tareas y flujo de trabajo de forma sencilla.

---

# Tecnologías utilizadas

## Frontend

- React
- TypeScript
- Tailwind CSS
- React Router

## Backend

- Node.js
- Express

---

# Estructura del proyecto

```txt
syncora/
│
├── client/ → frontend React
├── server/ → backend Express
└── docs/ → documentación del proyecto
```

---

# Funcionalidades actuales

- Arquitectura frontend básica
- Navegación entre páginas
- Componentes reutilizables
- Backend Express
- API REST básica
- Arquitectura por capas:
  - routes
  - controllers
  - services
