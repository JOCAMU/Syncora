


# Syncora



## Descripción general del proyecto

Syncora será una aplicación web pensada para organizar proyectos y tareas de trabajo de forma sencilla. La idea es crear una plataforma donde un equipo pueda ver el estado de un proyecto, organizar tareas y controlar el tiempo dedicado al trabajo.

La aplicación estará inspirada en herramientas de gestión de tareas y tableros Kanban, pero enfocada en una versión más simple y fácil de usar.

---

## Problema que intenta resolver

En muchos proyectos pequeños las tareas se organizan usando mensajes, notas o varias aplicaciones diferentes. Esto hace que a veces sea difícil saber:
- qué tareas faltan
- quién está trabajando en algo
- cómo va el proyecto
- cuánto tiempo se está dedicando

Syncora intenta reunir toda esa información en un mismo sitio para mejorar la organización del trabajo.

---

## Usuario objetivo

La aplicación está pensada para:
- pequeños equipos
- estudiantes
- freelancers
- personas que trabajan en varios proyectos al mismo tiempo

---

## Funcionalidades principales

- Crear y gestionar proyectos
- Crear tareas
- Cambiar el estado de las tareas
- Organizar tareas mediante un tablero Kanban
- Ver tareas pendientes y completadas
- Registrar horas de trabajo básicas
- Tener un dashboard simple con información general

---

## Funcionalidades opcionales

## Mejoras futuras

En futuras versiones se podrían implementar:

## Objetivo del proyecto

El objetivo principal es practicar el desarrollo de una aplicación fullstack usando React, TypeScript, Tailwind CSS y Express.

También servirá para practicar:
- organización de proyectos
- creación de APIs
- uso de React y hooks
- estructura de frontend y backend
- documentación técnica

Además, este proyecto también estará pensado como parte de mi portfolio personal.
