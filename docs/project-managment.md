# Gestión del proyecto

Para organizar el desarrollo de Syncora estoy utilizando Trello.

El tablero está dividido en varias columnas:

- Backlog
- Todo
- In Progress
- Review
- Done

Cada funcionalidad principal del proyecto tiene su propia tarjeta.

Dentro de cada tarjeta se añaden subtareas técnicas para dividir mejor el trabajo y organizar el desarrollo paso a paso.

La organización del proyecto permite llevar un seguimiento visual del progreso y mantener una estructura clara durante el desarrollo frontend y backend.

Actualmente el proyecto está dividido en dos partes principales:

- client/: frontend desarrollado con React, TypeScript y Tailwind
- server/: backend desarrollado con Node.js y Express
